Daylight_aw - Windows install (VST3)
====================================

1. Close your DAW.
2. Copy the folder "Daylight_aw.vst3" into:
       C:\Program Files\Common Files\VST3\
   (Windows asks for administrator permission - that's normal.)
3. Start your DAW and rescan plugins.
   REAPER: Options > Preferences > Plug-ins > VST > "Re-scan".
4. Look for "Daylight_aw" by "big_tyme_designs" in the effects list.

To update: close the DAW, replace the old Daylight_aw.vst3 folder with the new one.
Your sessions keep working - the effect choice and all settings are stored in the session.

Your presets, favourites and the User theme live in:
    Documents\big_tyme_designs\Daylight_aw\

Daylight_aw is free and open source (GNU AGPL v3). Not an official Airwindows release.
All sound comes from the original Airwindows code by Chris Johnson (MIT).
